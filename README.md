# 薪有数 · 工资记录助手

> 一款**完全本地运行**、**不联网、不上传任何数据**的个人工资记录与统计分析工具。  
> 月薪制 / 日薪制双模式，个税与五险一金自动估算，应用锁保护隐私，免费分享给大家使用。

## 📌 简介

「薪有数」帮助你记录、统计和分析每一笔工资收入。所有数据只保存在你自己的手机里，应用**不申请任何网络权限**，不会上传到任何服务器，安全放心。

## ✨ 功能特性

### 月薪制

- 按月记录工资收入，支持填写**固定月薪、五险一金（基数与比例）、个税、其他扣款**等构成
- 自动估算**五险一金**与**个人所得税**，按**年度累计预扣规则**精确计算每月到手金额
- 统计展示：今年累计、最高/最低单月、本年月均、较去年月均、月度趋势柱状图（长按可查看各月数值）
- 历史记录支持**年视图**与**列表视图**切换，左右滑动切换年份，长按多选删除，双击进入编辑
- 可设置每月发薪日，显示「距离下次发薪还有 X 天」

### 日薪制

- 按天记录日薪 / 时薪收入，支持多个时薪时间段、休息扣除、跨午夜时段自动计算
- 日历视图：点击选中、双击记账、长按多选、左右滑动切换月份
- 统计展示：今日累计、本月累计、已记天数、累计月均/日均、本年月均/本年日均

### 数据与安全

- **应用锁**：数字密码 / 图案解锁，含错误递增等待机制，防止暴力尝试
- 应用锁开启后支持**后台遮罩**、**防止截屏**，保护隐私
- **加密备份**：支持明文与密码加密（AES-GCM）两种方式导出 JSON 备份
- 数据导入：从备份文件一键恢复

### 其他

- 浅色 / 深色 / 跟随系统三种主题
- 首次启动展示并征得隐私政策与用户协议同意
- 设置中可随时查看或撤回同意

## 📲 安装

1. 前往 **[Releases](../../releases)** 下载最新版 APK（`薪有数-v1.0.apk`）
2. 在手机上允许「安装未知来源应用」
3. 安装后打开即可使用

> 要求：Android 8.0（API 26）及以上。

## 📖 使用说明

- **月薪制**：首页点击「记一笔」录入当月工资构成，系统自动算出五险一金、个税与到手金额。
- **日薪制**：在日历上选择日期记账，或按时间段录入时薪。
- **查看统计**：首页卡片展示累计与均数，点击/双击卡片可切换统计口径。
- **管理历史**：长按进入多选删除，双击记录进入编辑。

## 🔒 数据与隐私

- ✅ **不联网**：应用不申请任何网络权限，所有数据仅存于本机
- ✅ **本地加密存储**：核心数据 AES-GCM 加密，密钥由系统安全存储保护
- ✅ **隐私保护**：可选应用锁、后台遮罩、防截屏
- 完整条款见 **[隐私政策](隐私政策.md)** 与 **[用户协议](用户协议.md)**
